새로운 영상을 reconstruction 하는 방법

-------------------------------------------------------------------------------------------------
{RECONSTRUCTION}

1.reconstruction 하위 폴더를 만들어서 .mp4 파일 넣음

2-1.영상의 프레임 수 확인
ffprobe -v error \
  -select_streams v:0 \
  -count_packets \
  -show_entries stream=nb_read_packets \
  -of csv=p=0 \
  my_task/my_video.mp4

2-2.영상을 프레임별로 변환 (영상이 있는 디렉토리에서)
mkdir -p check_frames
ffmpeg -i putcup_input.mp4 check_frames/frame_%06d.png

3. 영상 처리
./run_pipeline.sh <영상경로> <기준프레임> <물체이름> <손방향>

ex) ./run_pipeline.sh dataset/whisking/whisking.mp4 125 whisk right

cf) 영상의 기준 프레임은 '물체가 심하게 가려지지않고,
물체 전체 형상이 잘 보이는 Frame 선택

4. reconstruction 결과를 Visualize 하는 명령어
cd ~/do-as-i-do/reconstruction/scripts
conda activate sam3d-objects

LAYOUT=/home/intern/do-as-i-do/reconstruction/dataset/cupmove/obj_tracking_out/cup/combined_visualization/layout_camera_frame_optimized.json

MESH_SCALE=$(python -c "
import json
d=json.load(open('$LAYOUT'))
print(d['translation_scale_optimization']['mesh_scale'])
")

echo "$MESH_SCALE"

python visualize_3d.py \
  --frames-dir /home/intern/do-as-i-do/reconstruction/dataset/appleinput/all_frames \
  --layout-json "$LAYOUT" \
  --mesh /home/intern/do-as-i-do/reconstruction/dataset/appleinput/video_segmentation/masks/frame_000020_masks/cup/cup.obj \
  --scale "$MESH_SCALE" \
  --translation-scale 1.0 \
  --hand-meshes /home/intern/do-as-i-do/reconstruction/dataset/cupmove/cupmove/all_hand_meshes.npz \
  --port 8080
